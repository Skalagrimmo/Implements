# FPE implementations

- [`fpe-v1.0.0-stable/`](fpe-v1.0.0-stable/README.md) — stable JavaScript FPE 1.0 implementation and its frozen public contract.
- [`fpe-c-v0.1.0/`](fpe-c-v0.1.0/README.md) — experimental, typed, portable C11 runtime iteration. It is intentionally separate from the stable package and is not yet wire-compatible with its JSON projection/snapshot contracts.

FPE is the PixelGen manifestation/view runtime, not a rigid-body physics engine. Physics, fracture and particle simulation are separate capabilities and are not claimed by these packages.
