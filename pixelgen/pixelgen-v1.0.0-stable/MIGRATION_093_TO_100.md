# Migration — PixelGen 0.9.3 → 1.0.0

The 1.0 promotion is metadata-only for current-feature 0.9.3 worlds.

```text
0.9.3 generator provenance stays 0.9.3
runtime_api             → 1.0.0
contract_manifest       → 1.0.0
render_api              stays 0.9.1
semantic fingerprint    unchanged
```

A migrated artifact does **not** pretend it was generated by 1.0.0. Generator provenance remains truthful.

Pre-corridor worlds still require regeneration. Unknown future generator versions remain rejected until compatibility is explicitly defined.

0.9.3 contract bundles can still be verified by PixelGen 1.0.0; the historical contract fingerprint is recognized as a readable legacy manifest.
